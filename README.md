# CompTIA A+ 220-1101 (Core 1) — Certification Exam Guide

A practical study guide for candidates preparing for the **CompTIA A+ 220-1101 (Core 1)** certification exam.

## Overview

The CompTIA A+ Core 1 exam covers foundational IT skills related to computer hardware, networking, mobile devices, virtualization, cloud computing, and troubleshooting.

This repository is intended as a study reference for learners who are building their IT support and technical troubleshooting knowledge.

> **Exam:** CompTIA A+ 220-1101
> **Core:** Core 1
> **Level:** Foundational IT

## Main Exam Topics

The 220-1101 exam focuses on the following areas:

### 1. Mobile Devices

Key concepts include:

* Smartphones and tablets
* Mobile device components
* Wireless connectivity
* Mobile device accessories
* Device configuration
* Mobile troubleshooting

### 2. Networking

Important networking concepts include:

* IPv4 and IPv6
* TCP/IP
* DNS and DHCP
* Network devices
* Ethernet
* Wireless networking
* Network ports and protocols
* Basic network troubleshooting

### 3. Hardware

Hardware knowledge is an important part of Core 1.

Topics include:

* CPUs
* RAM
* Motherboards
* Storage devices
* Power supplies
* GPUs
* Displays
* Input and output devices
* PC connectors and cables
* Printers

### 4. Virtualization and Cloud Computing

Candidates should understand fundamental concepts related to:

* Virtual machines
* Hypervisors
* Cloud computing
* Cloud service models
* Cloud deployment models
* Basic virtualization concepts

### 5. Hardware and Network Troubleshooting

Troubleshooting questions require candidates to analyze symptoms and determine appropriate solutions.

A useful troubleshooting approach is:

1. Identify the problem
2. Establish a theory of probable cause
3. Test the theory
4. Establish a plan of action
5. Implement the solution
6. Verify full system functionality
7. Document the findings

## Recommended Study Approach

A structured preparation process can make studying more manageable.

### Step 1 — Review the Exam Objectives

Start with the current official CompTIA exam objectives and use them as a study checklist.

### Step 2 — Learn the Fundamentals

Understand how hardware, networking technologies, mobile devices, and cloud technologies work instead of relying only on memorization.

### Step 3 — Practice

Use practice questions to identify knowledge gaps and become familiar with scenario-based questions.

### Step 4 — Get Hands-On Experience

Whenever possible, practice with real or virtual systems.

Examples include:

* Installing operating systems
* Configuring network connections
* Working with virtual machines
* Identifying hardware components
* Troubleshooting common PC problems

### Step 5 — Review Weak Areas

Track the topics where you make mistakes and spend additional time reviewing those concepts.
